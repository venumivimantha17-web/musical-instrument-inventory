# Python Musical Instrument Inventory

A simple Python project created to practice **classes and objects** using a musical instrument inventory.

## Features

* Create a `MusicalInstrument` class
* Use an `__init__` method to initialize objects
* Store instrument names and types as instance attributes
* Use the `play()` method to display a message
* Use the `get_fact()` method to return information about an instrument
* Create multiple instances from the same class

## Instruments

The project includes:

* **Oboe** — Woodwind
* **Trumpet** — Brass

## Concepts Practiced

* Python Classes
* Objects and Instances
* Instance Attributes
* Methods
* `self` parameter
* `__init__` method
* f-strings
* Returning values from methods
